# DotMiracle

The DotMiracle website: an SEO studio site served by Cloudflare Pages at https://dotmiracle.com.

The design came from the "Canopy SEO Studio" build (November 2026), rebranded to DotMiracle: the name and logo changed; the colours, fonts and engravings are as designed.

## Where things live

| Folder or file | What it holds |
| --- | --- |
| `content/library.json` | The words on every page: titles, summaries, sections, FAQs, and each page's search title and description. |
| `src/` | The React components and styles that lay the pages out. |
| `shared/search-pages.js` | The URL of each page, the home page title and description, and the contact email. |
| `static/` | Files copied as they are: fonts, images, the icons (`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`), `_redirects`, `_headers`, the worksheet in `resources/`. |
| `index.html` | The page shell: Google Tag Manager (`GTM-KWL6XQJZ`), fonts and default meta tags. |
| `scripts/pre-render.mjs` | Writes every page as its own HTML file and checks it (see below). |
| `public/` | The built site. Generated by the build and committed, because Cloudflare Pages publishes this folder as it is. Don't edit it by hand. |

`docs/` describes the previous site (before November 2026).

## Change the site

You need Node.js 20.19 or later. Once, after cloning:

```sh
npm ci
```

Then, after every change:

```sh
npm run build
```

Commit the changed files together with `public/`.

The build stops with a list of problems if any page breaks the site's SEO rules:

- a title longer than 60 characters, or one that doesn't end with `| DotMiracle`;
- a meta description missing or longer than 155 characters;
- two pages with the same title or description;
- a page without exactly one H1;
- a link to a page that doesn't exist, or a link to a section that isn't on the page;
- a page no link reaches from the home page;
- a service, location or industry page that doesn't link to and from its directory page;
- a redirect in `static/_redirects` that points to a page that doesn't exist;
- the word "Canopy" left on a page.

Each page gets its canonical URL, Open Graph tags and JSON-LD (Organization, WebSite, WebPage, BreadcrumbList, and Service, Article or ItemList; FAQPage only where the page shows FAQs). The build also writes `sitemap.xml`, `robots.txt` and `404.html`.

## Pages and URLs

Every URL is lowercase, uses hyphens and ends with a slash. `publicPath()` in `shared/search-pages.js` sets them from each entry's `kind` and `slug` in `content/library.json`:

| kind | URL |
| --- | --- |
| `service` | `/services/<slug>/` |
| `location` | `/locations/<slug>/` |
| `industry` | `/industries/<slug>/` |
| `note` | `/field-notes/<slug>/` |
| `case-study` | `/case-studies/<slug>/` |
| `hub` | `/services/`, `/locations/`, `/industries/`, `/field-notes/` |
| `studio` | `/about/`, `/contact/` |

The home page is built from the `home` and `approach` entries. A page's search title and description are `content[0].search.title` and `content[0].search.description` of its entry; the build adds ` | DotMiracle` to the title.

To add a page, add an entry with a new `id` and a unique `slug`, link to it from at least one other page, and run the build.

## Redirects

`static/_redirects` holds the 301 redirects that Cloudflare Pages applies. It sends the previous site's URLs to the closest page here (services the site no longer covers go to the home page), and other spellings such as `/locations/trivandrum/` to the canonical page. When you retire a page, add its old path there, with and without the trailing slash.

## Enquiries

There is no form service and no key. The forms (contact, free audit, client feedback) open the visitor's own email app with a message to `hello@dotmiracle.com` and their answers filled in; they check it and press Send. The next screen offers "Open it in Gmail", "Copy the brief" and "Save a copy" for visitors without an email app. `hello@dotmiracle.com` is a Cloudflare Email Routing address that forwards to the owner's inbox.

The message also lists the first page of the visit, a broad source (search, referral, Google Business Profile tag, direct) and the page the form was sent from, kept in the tab's sessionStorage (no cookies). Form opens and email hand-offs are pushed to `dataLayer` as `audit_form_open`, `contact_form_open` and `generate_lead`, without any form answers.

## Hosting notes (Cloudflare Pages)

- The Pages project publishes `public/` with no build command, so the committed `public/` is what goes live.
- Each branch gets a preview at `https://<branch-name-with-dashes>.dotmiraclecom.pages.dev`, served with `noindex`.
- `public/404.html` makes unknown URLs return a real 404.
- `static/_headers` adds `X-Robots-Tag: noindex` to the production copy at `https://dotmiraclecom.pages.dev`, so only `https://dotmiracle.com` is indexed, and lets browsers cache the hashed files in `/assets/` for a year.
- After deploying, submit `https://dotmiracle.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

## Icons and logo

Google Search shows a favicon from the home page's `<link rel="icon">` or `apple-touch-icon`, in ICO, PNG, GIF, JPEG, BMP, PPM or TIFF (not SVG). So the home page links three files made from the same mark: `favicon.ico` (16, 32 and 48 px), `favicon.svg` for browsers, and `apple-touch-icon.png` (180 px, square). The Organization structured data uses `images/dotmiracle-logo-512.png` (512 px; Google needs at least 112 px). If the mark changes, make all four again from the new SVG and keep their URLs.

Font licences are in `static/fonts/`.
